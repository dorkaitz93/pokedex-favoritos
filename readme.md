# Pokédex Favoritos

Aplicación web para buscar Pokémon usando la PokéAPI y guardarlos en una base de datos local (MySQL).

##  Tecnologías
* HTML5, CSS3
* JavaScript (Fetch API, Async/Await)
* PHP 8 (PDO)
* MySQL

## Instalación
1.  Clona este repositorio.
2.  Importa el archivo `database.sql` en tu gestor de base de datos (phpMyAdmin).
3.  Configura el archivo `backend/db.php` con tus credenciales de MySQL.
4.  Abre el proyecto en un servidor local (XAMPP).
